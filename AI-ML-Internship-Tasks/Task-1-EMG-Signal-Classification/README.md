# EMG Signal Classification (Prosthetic Control)

## Objective

The objective of this project is to classify EMG (Electromyography) hand gesture signals for prosthetic hand control using Machine Learning techniques.

## Dataset

EMG Dataset for Hand Gesture Recognition

## Work Performed

* Loaded EMG signal dataset
* Applied preprocessing techniques

  * Noise filtering
  * Signal normalization
* Trained Machine Learning classification model
* Classified hand gestures:

  * Open Hand
  * Close Hand
  * Grip

## Technologies Used

* Python
* NumPy
* Pandas
* Scikit-learn
* Matplotlib
* Seaborn

## Model Used

Random Forest Classifier

## Deliverables

* Accuracy Report
* Confusion Matrix
* Demo Gesture Prediction
* EMG Signal Visualization

## Result

The model successfully classified EMG hand gestures for prosthetic control applications with good prediction accuracy.
