# Crop Yield Prediction (Agri AI)

## Objective

The objective of this project is to predict crop yield using agricultural and environmental parameters through Machine Learning.

## Dataset

Crop Yield Prediction Dataset (India)

## Work Performed

* Loaded agricultural dataset
* Analyzed:

  * Rainfall
  * Temperature
  * Pesticide usage
* Performed preprocessing and feature encoding
* Built regression model for crop yield prediction

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn

## Model Used

Random Forest Regressor

## Deliverables

* Crop Yield Prediction Model
* Rainfall Analysis Graphs
* Temperature Analysis Graphs
* Feature Importance Analysis
* Farmer Recommendation Insights

## Result

The model successfully predicted crop yield based on environmental and agricultural conditions, providing useful insights for farmers and agricultural planning.
